## 2. Interface Contract
```go
package stream

import "time"

type SessionManager struct {
    IdleTimeout time.Duration // Default: 60 detik
}

func (sm *SessionManager) RegisterPing(channelID int64)
func (sm *SessionManager) StartReaperLoop(checkInterval time.Duration)
```

## 3. Implementation Steps
1. Setiap kali client HTTP meminta `.m3u8` atau segmen `.ts` dari channel, panggil `RegisterPing(channelID)` untuk memperbarui timestamp `lastAccess`.
2. Jalankan background goroutine (*reaper loop*) setiap interval tertentu (misal 10 detik).
3. Jika `time.Since(lastAccess) > sm.IdleTimeout`, panggil `StopStream(channelID)` dan bersihkan segmen HLS sementara dari direktori `/transcode`.

## 4. K-Threshold Verification Gate
Jalankan tes timeout session:

## 5. Red-Flag Traps
- **Dilarang:** Terjadinya goroutine leak atau race condition pada pembacaan timestamp (wajib menggunakan mutex atau atomic primitives).
