# Task M5.2: Docker Compose & Tmpfs Setup

## 1. Metadata
- **Task ID:** M5.2
- **Parallel Group:** G5
- **Prerequisites:** M5.1, M3.2
- **Target Files:**
  - `docker-compose.yml`
  - `.env.example`

## 2. Interface Contract
- Port mapping: `8080:8080`
- Volume mounts:
  - `./media:/media:ro` (Read-only akses video lokal)
  - `./data:/data` (Database SQLite & konfigurasi)
- Tmpfs mount:
  - `/transcode:rw,size=1G` (Buffer RAM disk untuk HLS segments)

## 3. Implementation Steps
1. Susun `docker-compose.yml` dengan restart policy `unless-stopped`.
2. Pasang tmpfs mount eksplisit pada `/transcode` dengan alokasi ukuran aman (misal 1GB).
3. Buat file `.env.example` yang mendefinisikan port default dan path folder media host.

## 4. K-Threshold Verification Gate
Jalankan validasi config compose:
```bash
docker compose config
```
*Kriteria Lolos:* File compose valid secara sintaksis dan parameter tmpfs terdefinisi dengan benar.

## 5. Red-Flag Traps
- **Dilarang:** Menghilangkan mount tmpfs pada `/transcode` (menyebabkan penulisan segmen video terus-menerus merusak umur drive SSD host).
