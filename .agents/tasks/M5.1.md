# Task M5.1: Multi-Stage Dockerfile

## 1. Metadata
- **Task ID:** M5.1
- **Parallel Group:** G1
- **Prerequisites:** None
- **Target Files:**
  - `Dockerfile`
  - `.dockerignore`

## 2. Interface Contract
- Stage 1: `golang:1.27-alpine` as builder (`CGO_ENABLED=0 GOOS=linux go build -ldflags="-s -w" -o /app/tv-stream ./cmd/server`).
- Stage 2: `alpine:3.21` or `debian:bookworm-slim` with FFmpeg installed via package manager.

## 3. Implementation Steps
1. Tulis `.dockerignore` untuk mengabaikan `/media`, `/transcode`, `.git`, `.agents`.
2. Susun Dockerfile multi-stage:
   - Install FFmpeg pada image runtime.
   - Buat direktori kerja `/app`, direktori data `/data`, dan mount target `/transcode`, `/media`.
   - Copy binary yang telah di-compile dari builder stage.
   - Set entrypoint: `["/app/tv-stream"]`.

## 4. K-Threshold Verification Gate
Jalankan validasi syntax Dockerfile:
```bash
docker build --target builder -t tv-stream-builder .
```
*Kriteria Lolos:* Build context valid dan instruksi Dockerfile berhasil di-parse tanpa peringatan fatal.

## 5. Red-Flag Traps
- **Dilarang:** Menjalankan container dengan root user tanpa batasan privilege jika memungkinkan, atau image size final > 200MB (kecuali ukuran dependensi runtime ffmpeg).
