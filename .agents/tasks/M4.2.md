# Task M4.2: Embedded Web Player (HLS.js)

## 1. Metadata
- **Task ID:** M4.2
- **Parallel Group:** G4
- **Prerequisites:** M3.1, M4.1
- **Target Files:**
  - `web/static/player.html`
  - `web/static/player.js`

## 2. Interface Contract
- Memuat file stream: `/channels/{id}/live.m3u8`.
- Fallback HTML5 native HLS untuk browser mobile/Safari, dan `hls.js` CDN/vendored untuk browser desktop.

## 3. Implementation Steps
1. Buat player view mandiri atau komponen player di dashboard.
2. Inisialisasi instance `Hls.isSupported()` dan attach ke elemen `<video>`.
3. Tambahkan visual error recovery jika buffer live mengalami stall atau segment reload error.

## 4. K-Threshold Verification Gate
Jalankan pengecekan DOM dan inisialisasi HLS script:
*Kriteria Lolos:* File HTML memuat tag `<video>` yang valid dan script player memanggil manifest URL `/channels/{id}/live.m3u8` tanpa syntax error.

## 5. Red-Flag Traps
- **Dilarang:** Autoplay dengan suara keras yang memicu browser block policy (wajib `muted` secara default pada autoplay).
