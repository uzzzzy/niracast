# Task M4.1: Web Dashboard UI

## 1. Metadata
- **Task ID:** M4.1
- **Parallel Group:** G2
- **Prerequisites:** M2.1
- **Target Files:**
  - `web/static/index.html`
  - `web/static/app.js`
  - `web/static/style.css`

## 2. Interface Contract
- Static web dashboard disajikan langsung via `http.FileServer` atau `embed.FS` dari server Go.
- Berinteraksi dengan REST API:
  - `GET /api/v1/channels`
  - `POST /api/v1/channels`
  - `DELETE /api/v1/channels/{id}`
  - `GET /api/v1/media`

## 3. Implementation Steps
1. Buat UI bersih berbasis Vanilla JS dan CSS modern (tanpa build tools seperti Webpack/Vite).
2. Tampilkan daftar channel, status siaran (Live / Idle), dan tombol cepat untuk melihat stream atau menyalin URL M3U.
3. Sediakan modal/form sederhana untuk menambah channel dan memetakan folder media.

## 4. K-Threshold Verification Gate
Jalankan validasi static files:
```bash
go test -v ./internal/api/...
```
*Kriteria Lolos:* File static berhasil di-serve dengan MIME type yang benar (`text/html`, `application/javascript`, `text/css`) dan status HTTP 200.

## 5. Red-Flag Traps
- **Dilarang:** Memasukkan dependensi runtime Node.js/npm untuk dashboard web (wajib murni static single-file / Vanilla).
