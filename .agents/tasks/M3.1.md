## 2. Interface Contract
```go
package stream

import "context"

type StreamConfig struct {
    ChannelID     int64
    SourcePath    string
    SeekSeconds   float64
    OutputDir     string // Direktori tmpfs /transcode/channels/{id}
    CopyCodec     bool
}

type ProcessController interface {
    StartStream(ctx context.Context, cfg StreamConfig) error
    StopStream(channelID int64) error
    IsRunning(channelID int64) bool
}
```

## 3. Implementation Steps
1. Buat direktori output `/transcode/channels/{id}` jika belum ada.
2. Bangun argumen command FFmpeg:
   - `-ss <SeekSeconds> -re -i <SourcePath>`
   - `-c:v libx264 -preset veryfast -b:v 2500k -c:a aac -b:a 128k` (atau `-c copy` bila flag aktif)
   - `-f hls -hls_time 2 -hls_list_size 5 -hls_flags delete_segments+append_list <OutputDir>/live.m3u8`
3. Eksekusi via `exec.CommandContext` dan simpan pointer `*os.Process` ke dalam session registry yang aman terhadap konkurensi (`sync.RWMutex`).
