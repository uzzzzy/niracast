## 2. Interface Contract
```go
package timeline

import "time"

type PlayoutItem struct {
    MediaID     int64
    FilePath    string
    SeekSeconds float64 // Offset waktu mulai dari awal file video
    RemainingSec float64
}

type TimelineCalculator interface {
    GetCurrentPlayout(channelID int64, now time.Time) (*PlayoutItem, error)
}
```

## 3. Implementation Steps
1. Ambil seluruh playlist aktif channel dalam urutan loop kontinu (*flood playout*).
2. Hitung total durasi playlist `T_total`.
3. Hitung selisih waktu dari titik awal epoch channel `(now.Unix() % T_total)`.
4. Iterasi item playlist untuk menemukan video yang tepat sedang tayang beserta `SeekSeconds`.
