## 2. Interface Contract
```go
package stream

import "tv-stream/internal/ingest"

type PipelineProfile struct {
    CanCopyVideo bool
    CanCopyAudio bool
    FFmpegArgs   []string
}

func OptimizePipeline(meta *ingest.MediaMetadata) PipelineProfile
```

## 3. Implementation Steps
1. Periksa codec sumber dari metadata video.
2. Jika video codec adalah `h264` dan audio codec adalah `aac`, aktifkan copy mode (`-c:v copy -c:a copy`).
3. Jika codec berbeda (misal `hevc`, `vp9`, atau audio `ac3`), gunakan software encoder (`-c:v libx264 -c:a aac`).

## 4. K-Threshold Verification Gate
Jalankan tes profiling encoder:
```bash
go test -v -run TestOptimizer ./internal/stream/...
```
*Kriteria Lolos:* Mengembalikan flag copy murni jika input adalah h264/aac dan re-encode jika input berbeda.

## 5. Red-Flag Traps
- **Dilarang:** Memaksa copy stream pada codec yang tidak kompatibel dengan HLS standard (misal VP8 atau DTS audio).
