## 2. Interface Contract
Endpoints REST API:
- `GET /api/v1/channels`: List semua channel
- `POST /api/v1/channels`: Buat channel baru (`{ "number": 1, "name": "Classic Movies" }`)
- `PUT /api/v1/channels/{id}`: Update nama/nomor channel
- `DELETE /api/v1/channels/{id}`: Hapus channel
- `POST /api/v1/channels/{id}/playlist`: Susun item media ke dalam playlist channel

## 3. Implementation Steps
1. Buat DTO dan SQL query untuk operasi CRUD channel dan relasi playlist.
2. Gunakan `net/http` router standar (Go 1.22+ pattern routing atau chi) untuk endpoint REST.
3. Validasi keunikan nomor channel (`number UNIQUE`).

## 4. K-Threshold Verification Gate
Jalankan unit test API handler dengan `httptest.NewRecorder()`:
```bash
go test -v ./internal/api/...
```
*Kriteria Lolos:* Status HTTP 200/201/400 sesuai spesifikasi; nomor channel duplikat mengembalikan HTTP 409/400.

## 5. Red-Flag Traps
- **Dilarang:** Menelan (*swallow*) error query SQL tanpa mengembalikan pesan error yang bermakna ke client HTTP.
