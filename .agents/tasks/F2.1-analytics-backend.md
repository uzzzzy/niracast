## Interface Contract
- **Inputs**: HLS requests (`GET /channels/{id}/live.m3u8`, `GET /channels/{id}/{file}.ts`).
- **Outputs**:
  - `GET /api/v1/analytics/live` -> `{"total_viewers":N,"channels":[{"channel_id","viewers","restarts","last_error"}]}`
  - `GET /api/v1/analytics/timeseries?range=1h|24h|7d|30d&channel_id=` -> `{"range","points":[{"ts","viewers_peak","bytes_out","watch_sec"}]}`
  - `GET /api/v1/analytics/top-media?range=` -> `{"items":[{"media_id","title","watch_sec"}]}`
  - SSE events `viewers.update` (ChannelID 0 = total, Data: viewers) every ~5 s, and `channel.health` (Data: restarts, last_error). SSE `snapshot` includes viewer counts.
- **Invariants**:
  - A client is active if it requested a manifest or segment in the last ~10 s. Client id = SHA-256(daily in-memory salt + `auth.ClientIP(r)` + User-Agent). No raw IPs stored, no GeoIP.
  - Observe at request arrival (manifest handler can block 20 s). Byte-counting `ResponseWriter` wrapper must implement `Unwrap()`.
  - Schema change is additive `CREATE TABLE IF NOT EXISTS` (`analytics_minute`, `analytics_daily`); no `user_version` bump. Retention: minutes 30 d, daily 1 y.
  - Routes are under `/api/v1/` so auth is default-deny; do not make them public.
  - Flusher writes per minute, final flush on shutdown (defer registered after `defer conn.Close()`), `now` test hook.
