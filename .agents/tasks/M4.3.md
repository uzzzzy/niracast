## 2. Interface Contract
Endpoints Feed:
- `GET /iptv/channels.m3u` (`Content-Type: application/x-mpegurl`)
- `GET /iptv/epg.xml` (`Content-Type: application/xml`)

Format M3U:
```text
#EXTM3U
#EXTINF:-1 tvg-id="channel-1" tvg-chno="1" tvg-name="Classic Movies",Classic Movies
http://<host>/channels/1/live.m3u8
```

Format XMLTV EPG:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE tv SYSTEM "xmltv.dtd">
<tv generator-info-name="tv-stream">
  <channel id="channel-1">
    <display-name>Classic Movies</display-name>
  </channel>
  <programme start="20261017120000 +0000" stop="20261017140000 +0000" channel="channel-1">
    <title>Sample Movie Title</title>
  </programme>
</tv>
```

## 3. Implementation Steps
1. Buat generator M3U yang mengiterasi tabel channels dan menyusun baris `#EXTINF`.
2. Buat generator XMLTV yang mengonversi jadwal timeline 24 jam ke depan menjadi tag `<programme>`.
3. Pasang caching in-memory sederhana untuk EPG guna menghindari kalkulasi XML berulang pada request client berurutan.

## 4. K-Threshold Verification Gate
Jalankan tes validasi struktur output M3U & XML:
```bash
go test -v ./internal/feed/...
```
*Kriteria Lolos:* Header `#EXTM3U` valid dan payload XMLTV lolos parsing `xml.Unmarshal` standar tanpa error.

## 5. Red-Flag Traps
- **Dilarang:** Format timestamp XMLTV yang tidak sesuai standar `YYYYMMDDhhmmss +0000` (dapat menyebabkan EPG gagal dibaca oleh Jellyfin/Kodi).
