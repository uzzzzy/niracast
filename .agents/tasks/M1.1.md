# Task M1.1: SQLite Schema & Database Init

## 1. Metadata
- **Task ID:** M1.1
- **Parallel Group:** G0
- **Prerequisites:** None
- **Target Files:**
  - `go.mod`
  - `internal/db/sqlite.go`
  - `internal/db/schema.sql`
  - `internal/db/sqlite_test.go`

## 2. Interface / Schema Contract
- Driver: Pure-Go SQLite (`modernc.org/sqlite`).
- Tabel DDL:
  - `channels`: `id INTEGER PRIMARY KEY, number INTEGER UNIQUE, name TEXT, created_at DATETIME`
  - `media_files`: `id INTEGER PRIMARY KEY, path TEXT UNIQUE, filename TEXT, duration_sec REAL, codec_video TEXT, codec_audio TEXT, width INTEGER, height INTEGER`
  - `playlists`: `id INTEGER PRIMARY KEY, channel_id INTEGER, name TEXT, loop_mode TEXT`
  - `schedules`: `id INTEGER PRIMARY KEY, channel_id INTEGER, media_id INTEGER, start_time DATETIME, duration_sec REAL, position_order INTEGER`

## 3. Implementation Steps
1. Inisialisasi go module `tv-stream`.
2. Pasang dependensi `modernc.org/sqlite`.
3. Buat fungsi `InitDB(dbPath string) (*sql.DB, error)` yang menjalankan migrasi `schema.sql` dan mengaktifkan WAL mode (`PRAGMA journal_mode=WAL;`).

## 4. K-Threshold Verification Gate
Jalankan unit test database in-memory:
```bash
go test -v ./internal/db/...
```
*Kriteria Lolos:* Database terinisialisasi, tabel terbentuk sempurna tanpa error runtime.

## 5. Red-Flag Traps
- **Dilarang:** Menggunakan `mattn/go-sqlite3` atau library yang memerlukan GCC / CGO aktif (`CGO_ENABLED=0` wajib bekerja).
