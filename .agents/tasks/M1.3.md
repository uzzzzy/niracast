## 2. Interface Contract
```go
package ingest

type MediaMetadata struct {
    Path        string
    DurationSec float64
    VideoCodec  string
    AudioCodec  string
    Width       int
    Height      int
}

func ProbeMedia(filePath string) (*MediaMetadata, error)
```

## 3. Implementation Steps
1. Eksekusi `ffprobe -v quiet -print_format json -show_format -show_streams <filePath>` via `exec.CommandContext`.
2. Unmarshal output JSON ke struct internal Go.
3. Ekstraksi durasi riil (float64) dan informasi stream codec video pertama dan stream audio pertama.

## 4. K-Threshold Verification Gate

```bash

```
*Kriteria Lolos:* Durasi, resolusi, dan codec diekstraksi tepat tanpa panik pada format JSON ffprobe standar.
